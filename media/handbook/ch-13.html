13Troubleshooting & Diagnostics

When something's not right

Most problems in TycoonAgents trace back to one of a handful of root causes — hooks, a missing theme selection, a stale bridge, or a metrics number that only looks wrong. This chapter is a quick-reference triage before you file a bug report.

§ 13.1 · Panel is empty, no agents show up hooks aren't installed

The agent visualization is driven entirely by Claude Code hooks. If nothing appears, hooks likely aren't installed for this project, or your session hasn't picked up a recent install.

01

Open Settings → Hook health and use Troubleshoot → Fix to repair the install.

02

Restart your Claude Code session so it picks up the newly installed hooks.

§ 13.2 · Theme art isn't showing selection or frames

Two likely causes: no theme is currently selected, or the theme is selected but some of its entities are missing frames.

Note

Check the Theme Picker first to confirm a theme is active. If it is and art is still missing, see Chapter 7 for the health check and the Resume fix.

§ 13.3 · UEFN chip is gray bridge not staged, or engine not restarted

A gray UEFN chip means the Power Tools bridge either hasn't been staged into your project yet, or UEFN hasn't been restarted since it was.

01

Revisit Setup and confirm the bridge staging step completed (Chapter 12).

02

Restart UEFN so it picks up the bridge from Content/Python.

§ 13.4 · Metrics numbers look wrong usually not a bug

A gap between "dispatched" and "completed" task counts is expected, not an error — it means some dispatched tasks never posted a completion (abandoned or simply unfinished), not that something is silently broken. See Chapter 10 for the full explanation.

§ 13.5 · Reporting a bug Report a bug / Diagnostics
Screenshot

Settings — Report a bug / Diagnostics section.

01

Open Settings → Report a bug / Diagnostics and choose Generate diagnostic report.

02

The report is sanitized — absolute file paths and secrets are stripped before it's copied to your clipboard — and ready to paste wherever you're reporting the issue.

Tip

You can also run the /tycoon-diagnose skill directly from Claude Code for a deeper, AI-reasoned pass over your project's own configuration.

§ 13.6 · When all else fails reinstall is safe

Reinstalling through the setup wizard is safe to reach for. Your state survives an update — build progress and earned badges persist on the host side, not in the webview — so a reinstall won't wipe your progress.
