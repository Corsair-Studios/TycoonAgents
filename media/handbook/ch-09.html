09Settings Reference

Two layers of settings

TycoonAgents has editor-level settings (the ones your editor's Settings UI knows about) and an in-panel Settings tab with richer, live controls. This chapter lists both, so you know where to look for a given knob.

§ 9.1 · Editor settings key · default · what it does
Setting keyDefaultWhat it does
tycoonagents.autoShowtrueAutomatically opens the live agent panel when a workspace opens.
tycoonagents.idleFreezeMinutes3Freezes an agent's live time after this many minutes with no activity.
tycoonagents.sanityCapMinutes15Hard cap on any single active stretch, in minutes.
tycoonagents.delegationWarnThreshold5Warns in Delegation Health once the orchestrator's direct search count exceeds this in a session.
tycoonagents.themeImageProvideropenaiWhich image provider to use — openai or gemini.
tycoonagents.geminiApiKey Fallback Gemini API key. Prefer the secure field in Themes > Theme Builder.
tycoonagents.openaiApiKey Fallback OpenAI API key. Prefer the secure field in Themes > Theme Builder.
tycoonagents.geminiModel Image model override for Gemini. Leave blank to always use the latest recommended model.
tycoonagents.openaiModel Image model override for OpenAI. Leave blank to always use the latest recommended model.

Note

Leaving the model overrides blank isn't a placeholder — it's the recommended setting. TycoonAgents resolves to the newest supported model for your chosen provider automatically.

§ 9.2 · In-panel Settings tab what each section controls
01

Hook health. Shows whether Claude Code's hooks are installed for this project, with buttons to install or repair them.

02

Path Health. Shows how each UEFN-related path was resolved — override, environment, auto-detected, or NOT FOUND — along with every candidate location that was tried. It also detects whether Epic's Verse VS Code extension is installed and enabled, and warns separately when the extension is installed but disabled rather than missing entirely. You can set explicit path overrides here; they're persisted to .claude/tycoon/uefn-paths.json. A copy-paste diagnostic block is available too, formatted to hand to your own Claude session for guided fixing. See Chapter 13 for the related troubleshooting callout and the environment-variable overrides it honors.

03

Delegation style. Choose between Direct and Team Leads delegation modes, plus a separate Review pass checkbox (on by default) — when enabled, a second agent reviews each specialist's work before it's reported done.

04

Project Plan. Turns the optional phase/task planning feature on or off (see Chapter 11).

05

Agents. Per-role model and agent choices — which model each specialist role runs on.

06

Keyword routing. The word lists that decide which specialist a task's description routes to.

07

Delegation Health. A live look at how well delegation is working for this session — see Chapter 10 for how to read it.

08

Context budget. Controls related to how much context gets passed between agents.

09

Report a bug / Diagnostics. Generates a sanitized diagnostic report you can share when something isn't working — see Chapter 13.
