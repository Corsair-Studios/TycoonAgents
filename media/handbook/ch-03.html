Panel Tour

Orientation
The panel has four tabs and a menu. This chapter is a map of each one, so the rest of the handbook can point at specific tabs without re-explaining them.
§ 3.1 · Theater
the scene itself

Theater is the default tab and the one most people leave open. Agents appear on stage as characters that walk to build sites, hammer away while a task is in progress, and emote when it completes. A HUD shows badges you've earned and your current rebirth (prestige) level — rebirthing resets progress in exchange for permanent milestones, and it's driven entirely by real delegation activity, not anything scripted.

§ 3.2 · Metrics
per-agent table

Metrics lists every agent that has run in this workspace with a row per agent: tasks completed, tokens used, and the model it ran on. Each row also carries a "vs. orch." bar — tasks completed relative to the busiest agent — paired with an "Nx cheaper" badge that expresses how much less that agent's model costs relative to the orchestrator's, without ever showing a dollar figure. See Chapter 10 for how to read the cost lens in full.

Screenshot
Metrics tab — per-agent table with vs. orch. bars.
§ 3.3 · Delegation
where the work actually went

Delegation zooms out to the whole session: a chart of delegated work by model tier, a coordination line showing how much the orchestrator itself is doing, and a dispatched-vs-completed reconciliation (the gap between the two is normal — it reflects abandoned or unfinished spawns, not a bug). Below that sits the same per-agent table as Metrics, an Opus-leak meter flagging work that should have been delegated but wasn't, and a savings headline like "avoided ~N%." Chapter 10 covers all of these in depth.

Screenshot
Delegation tab — tier chart, reconciliation line, and savings headline.
§ 3.4 · Project Plan
only when enabled

Project Plan shows phases, tasks, and gates for larger bodies of work tracked through the plan feature. This tab only appears when the Project Plan feature is enabled for the workspace — it's on by default for new installs, but existing projects that were set up before it shipped stay off unless the feature is turned on explicitly. Chapter 11 is the full reference.

Screenshot
Project Plan tab — phases and tasks with gate checkpoints.
§ 3.5 · The menu
everything else

A menu sits alongside the tabs with four entries:

  • About — version and quick project info.
  • Settings — the full settings surface (Chapter 09).
  • Themes — switch active theme or open the Theme Maker (Part II).
  • Troubleshoot & Fix — runs diagnostics and offers repairs (Chapter 13).
Tip

If delegation looks like it isn't working — no agents ever appear on stage — check the Delegation tab's Opus-leak meter first. It's usually the fastest way to spot work that's quietly bypassing the doctrine.

§ 3.6 · Status chips
upper-left of the stage

A row of small chips sits in the upper-left of the Theater stage, alongside the agents themselves. Each chip represents an engine integration — UEFN first, then the rest alphabetically (Blender, Godot, Roblox, Unity, Unreal). They're informational only: hover a chip to read its tooltip, but clicking it doesn't do anything.

Screenshot
SCREENSHOT — the chip row in the upper-left of the stage (e.g. a UEFN chip glowing green beside a Godot chip in ready state).

The UEFN chip appears once the UEFN bridge is installed, and has two states:

StateColorMeaning
ConnectedGreen glowHeartbeat received in the last 15 seconds — agents can use the uefn_* MCP tools.
OfflineAmberNo recent heartbeat. Reopen the UEFN project so the bridge auto-starts, and confirm the Python Editor Script Plugin is enabled.

The engine chips (Godot, Unity, Unreal, Roblox, Blender) appear when TycoonAgents detects that engine's project files (for example project.godot, a ProjectSettings/ folder, a *.uproject, a .rbxl or default.project.json, or a .blend file), OR that engine's pack, skill, or agents are installed, OR an MCP entry for it exists. Any one of those three triggers is enough for the chip to show up. Each engine chip has five possible states:

StateColorMeaningWhat to do
ConnectedGreen glowMCP probed and answering — live tools are available.Nothing — ready to use.
OfflineAmberMCP is configured but not responding.Start the local MCP server.
ConfiguredSolid greenA stdio MCP entry is present but not yet started.Start its server to enable live tools.
ReadyCyanThe engine's pack or skill is installed, but no MCP is set up.Nothing required — add an MCP entry for live tools.
SetupGrayA project for that engine was detected, but nothing is installed yet.Install the engine's pack from the catalog.
Not the same as

The install wizard's Optionals step has its own row of chips (Playwright, Godot, Unity, Unreal Engine, UEFN) — those are toggleable and clicking one selects a skill to install. The status chips described here are a different thing: read-only indicators on the live stage, not selectable at all. See Chapter 02 for the wizard.

§ 3.7 · Rebirth
prestige, badge previews, and trophy cups

Rebirth is the panel's prestige loop. Triggering it resets progress in exchange for permanent gains: every built object is wiped — the whole build queue has to be rebuilt from scratch — and the badge requirements re-roll for the next cycle. In exchange, each completed rebirth permanently and compoundingly increases two stats: build speed goes up 20% per rebirth (1.2 raised to your rebirth count), and agent defense goes up 10% per rebirth (1.1 raised to your rebirth count) — agents and turrets deal more damage to rivals at higher defense.

The badges popup only ever previews the next rebirth — one tier ahead of your current one, never further — and includes a stat line showing your current build-speed and defense percentages against what they'll become once you reach it.

Each rebirth tier permanently unlocks its own perk, and the tiers stack — nothing you've already unlocked goes away:

RebirthUnlocks
1The buildable weapons rack, which unlocks ranged weapons.
2The buildable defensive turret (for themes that have one) and team stand-up huddles — agents ring up around a rotating speaker who shows idea and team bubbles while listeners react, and one occasionally dozes off.
3The disco dance party.
4The dance-off.
5The victory-lap upgrade — party lights and confetti on a wave clear.
6The gold party palette, plus agent sparring exhibitions — friendly melee-and-block duels with spectators and one winner's cheer. The dazed and angry expression bubbles stay reserved for real combat; sparring never uses them.

Completed rebirths are marked by trophy cups. Hovering a cup shows which rebirth it represents and what that tier's perk was.
