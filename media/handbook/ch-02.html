02

Installation & First-Run Setup

Get running
Install the extension, let it open the panel, and walk through the two-step setup wizard once. Everything here runs on first launch and is skipped automatically after that.
§ 2.1 · What you need
by tier

TycoonAgents is built in tiers — each one only needed for the features it unlocks. The core panel (Tier 0) needs nothing beyond itself; everything else is optional on top of it.

TierUnlocksRequires
0 · Core panel Scene, metrics, delegation visualization A VS Code-family IDE (VS Code, Antigravity, Cursor, Windsurf, Insiders) + the Claude Code extension/CLI, plus Node.js v18+ on PATH — the activity hooks that feed the scene run through it.
1 · Theme authoring Generating custom art themes An OpenAI or Gemini API key, used at authoring time only — the shipped plugin makes zero runtime AI calls.
2 · UEFN bridge / Power Tools Live-editor inspection, audits, MCP tools UEFN installed with the project open, the Python Editor Script Plugin enabled (the in-editor bridge runs on UEFN's own embedded Python — no system Python needed for the in-editor tools), and Node.js v18+ on PATH (the MCP client launches the bridge's server via node).
3 · Verse analyzer uefn_verse_check real compiler diagnostics System Python 3 on PATH (python / python3 / py), Epic's Verse VS Code extension installed in any supported IDE, and the project opened at least once in UEFN.

Node.js v18+ is the one prerequisite that runs through every tier: the activity hooks at Tier 0, and the bridge's MCP server on top of that at Tier 2.

Note

Each tier is needed only for its own features — the core panel needs nothing beyond Tier 0. See Chapter 12 for the UEFN bridge and Chapter 13 for the no-VS-Code Verse analyzer route.

§ 2.2 · Installing the extension
VSIX or marketplace

Install TycoonAgents either from a .vsix file or from your editor's extension marketplace, the same way you'd install any other extension. Once it's active in a workspace, the panel opens automatically — this is controlled by the tycoonagents.autoShow setting, which defaults to true. If you'd rather open it yourself, turn that setting off in Settings (Chapter 09) and launch the panel from the command palette or the activity bar icon.

§ 2.3 · The first-run wizard
two steps, step 1 required

The first time TycoonAgents opens in a workspace, it shows a short setup wizard. Returning users — anyone who has already completed it in this workspace — skip straight to the panel.

Step 1 — Install hooks (required)

01

Choose a delegation mode: Orchestrator mode (flat — one orchestrator dispatches directly to every specialist) or Team Lead mode (hierarchical — adds a coordination layer for larger teams of agents). If you're not sure, Orchestrator mode is the simpler starting point.

02

Click through to write the delegation doctrine into your project's CLAUDE.md. This is the instruction set that tells the orchestrator which work must be routed to which specialist — without it, nothing gets delegated and the stage stays empty.

03

TycoonAgents creates the agent roster in .claude/agents — one definition file per specialist, tuned to your project type (see Chapter 03 for the full roster).

Screenshot
First-run wizard, Step 1 — delegation mode choice and hook install.

Step 2 — Optional extras

01

Ignore tycoon logs — the installer detects which version control system your project actually uses and writes the matching ignore file(s): .gitignore for Git, .p4ignore for Perforce, or .urcignore for Unreal Revision Control. The ignore files also ignore each other, so a project using more than one doesn't end up tracking the others' ignore files. On Perforce and Unreal Revision Control specifically, the ignore file additionally excludes .mcp.json, CLAUDE.md, and .claude/, so TycoonAgents' own tooling files are never pushed into a shared project.

02

Install skill chips — adds bundled Claude Code skills relevant to your project.

03

UEFN detection card — if TycoonAgents detects a UEFN project, a card offers "Yes, set up UEFN." Accepting it stages the Python bridge into your project's Content/Python folder and installs the Verse Expert and UEFN Auditor specialist agents. See Chapter 12 for what the bridge does.

04

Advanced tuning — a link straight to Settings (Chapter 09) if you want to change parallel-agent limits or other defaults before you start.

Screenshot
First-run wizard, Step 2 — optional extras card.
Note

Step 2 is entirely optional and can be skipped. Step 1 is the only part that's required to get delegation working at all.

§ 2.4 · Returning users
no repeat prompts

Once Step 1 has completed for a workspace, TycoonAgents won't show the wizard again on future opens — the panel opens straight into the Theater tab. If you want to revisit the wizard's choices later (switch delegation modes, re-run UEFN setup, and so on), use the panel's Settings menu rather than waiting for the wizard to reappear.
