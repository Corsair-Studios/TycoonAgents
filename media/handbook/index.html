TycoonAgents Handbook

Everything you need to install TycoonAgents, wire up delegation, build a theme, and read the panel like a pro — from first launch to troubleshooting the deep stuff.

What is TycoonAgents?

TycoonAgents is a VS Code‑compatible extension that turns your Claude Code multi‑agent delegation into a living tycoon scene. An orchestrator agent hands work off to cheap specialist agents, hooks record every dispatch and completion, and the panel renders those agents as characters who walk the stage, build, emote, earn badges, and even rebirth (prestige) as your project grows. The extension itself makes zero runtime AI calls — it only observes hooks and renders what already happened. The visuals are a theme: an art skin you generate once with the built-in Theme Maker, then the panel renders it forever, fully offline.

This handbook is split into three parts. Part I gets you installed and oriented. Part II walks the Theme Maker end to end. Part III is a reference for settings, the metrics/delegation tabs, the project plan feature, UEFN Power Tools, and troubleshooting.
