04

API Keys & Providers

Before you build
The Theme Maker needs an image-generation API key to turn your creative direction into art. This is the one place TycoonAgents talks to an external AI provider — and only when you tell it to.
§ 4.1 · Authoring-time only
what the key is for

An API key is only ever used while you're generating a theme. Once the images are generated, they're saved locally as part of the theme (Chapter 06 covers exactly what gets stored), and the extension never calls the image API again to render the scene — it just plays back the stored frames. Runtime rendering has no AI dependency at all.

§ 4.2 · Choosing a provider
two options
Provider Where to get a key Notes
OpenAI GPT Image (recommended default) platform.openai.com → API keys Requires a paid OpenAI account with credits.
Google Gemini image models (community nickname "Nano Banana") aistudio.google.com → Get API key Has a free tier, good for experimenting before committing to a paid provider.
Note

Neither provider is required over the other — pick whichever you already have an account with. OpenAI GPT Image is the recommended default for consistency across a full theme's worth of images.

§ 4.3 · Entering and storing your key
where it lives
01

Open the theme generation form (Chapter 05) and enter your key in the provider section. Your editor stores it securely rather than writing it into any project file.

02

As a fallback, you can also set a key via Settings using tycoonagents.openaiApiKey or tycoonagents.geminiApiKey — useful if you want the key pre-filled across the workspace rather than entering it each time.

§ 4.4 · Picking a model
latest by default

Model pickers default to "Latest (recommended)." TycoonAgents never hardcodes a specific model version internally — the default always tracks whatever the provider currently considers latest. If you want to pin an older or cheaper model instead, use the dropdown, or set an override permanently via tycoonagents.openaiModel / tycoonagents.geminiModel.
