# Pose Guides

Reference images for the four-frame walk cycle used on row 1, cells 1-4 of
the character board.

- `humanoid-walk-reference.png` (1440x600) — upright humans/robots (biped).
- `quadruped-walk-reference.png` (2048x384) — dog/cat-like bodies (quadruped).

Each guide shows the four canonical walk-cycle frames left to right, mapping
directly to row 1 / cells 1-4 of the character board.

## Colour code

- Red = right / near-side limbs
- Blue = left / far-side limbs

Colours identify anatomy, not appearance (e.g. clothing or fur colour). All
figures face screen-right.

## Scope

- Humanoid guide: upright humans and robots.
- Quadruped guide: dog/cat-like bodies.
