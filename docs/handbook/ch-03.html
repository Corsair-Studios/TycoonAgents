Panel Tour

Orientation
The panel has four tabs and a menu. This chapter is a map of each one, so the rest of the handbook can point at specific tabs without re-explaining them.
§ 3.1 · Theater
the scene itself

Theater is the default tab and the one most people leave open. Agents appear on stage as characters that walk to build sites, hammer away while a task is in progress, and emote when it completes. A HUD shows badges you've earned and your current rebirth (prestige) level — rebirthing resets progress in exchange for permanent milestones, and it's driven entirely by real delegation activity, not anything scripted.

§ 3.2 · Metrics
per-agent table

Metrics lists every agent that has run in this workspace with a row per agent: tasks completed, tokens used, and the model it ran on. Each row also carries a "vs. orch." bar — tasks completed relative to the busiest agent — paired with an "Nx cheaper" badge that expresses how much less that agent's model costs relative to the orchestrator's, without ever showing a dollar figure. See Chapter 10 for how to read the cost lens in full.

§ 3.3 · Delegation
where the work actually went

Delegation zooms out to the whole session: a chart of delegated work by model tier, a coordination line showing how much the orchestrator itself is doing, and a dispatched-vs-completed reconciliation (the gap between the two is normal — it reflects abandoned or unfinished spawns, not a bug). Below that sits the same per-agent table as Metrics, an Opus-leak meter flagging work that should have been delegated but wasn't, and a savings headline like "avoided ~N%." Chapter 10 covers all of these in depth.

§ 3.4 · Project Plan
only when enabled

Project Plan shows phases, tasks, and gates for larger bodies of work tracked through the plan feature. This tab only appears when the Project Plan feature is enabled for the workspace — it's on by default for new installs, but existing projects that were set up before it shipped stay off unless the feature is turned on explicitly. Chapter 11 is the full reference.

§ 3.5 · The menu
everything else

A menu sits alongside the tabs with four entries:

  • About — version and quick project info.
  • Settings — the full settings surface (Chapter 09).
  • Themes — switch active theme or open the Theme Maker (Part II).
  • Troubleshoot & Fix — runs diagnostics and offers repairs (Chapter 13).
Tip

If delegation looks like it isn't working — no agents ever appear on stage — check the Delegation tab's Opus-leak meter first. It's usually the fastest way to spot work that's quietly bypassing the doctrine.
