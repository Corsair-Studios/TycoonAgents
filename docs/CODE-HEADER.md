# Source Attribution Header

Every source file in TycoonAgents begins with a short attribution header. It is a **courtesy credit, not a restriction** — end users may remove it, and we neither prevent nor object to that.

**Fields**
- Project: **TycoonAgents**
- Author: **https://x.com/thetrashbyrd**
- Releases: **repository not yet created** — replace the placeholder URL once it exists.

> TODO: when the public repo + releases page exist, replace `https://github.com/TODO/TycoonAgents/releases` everywhere with the real URL (and update this doc + the README).

## Variants by language

### C-style block (TypeScript, JavaScript, C/C++, etc.)
```
/*
 * TycoonAgents - https://x.com/thetrashbyrd
 * Releases: https://github.com/TODO/TycoonAgents/releases   (TBD - repo not yet created)
 * Attribution header - optional; end users may remove it.
 */
```

### Line comments (TypeScript / JavaScript, also acceptable)
```
// TycoonAgents - https://x.com/thetrashbyrd
// Releases: https://github.com/TODO/TycoonAgents/releases   (TBD - repo not yet created)
// Attribution header - optional; end users may remove it.
```

### Hash (Python, PowerShell, shell, YAML, TOML)
```
# TycoonAgents - https://x.com/thetrashbyrd
# Releases: https://github.com/TODO/TycoonAgents/releases   (TBD - repo not yet created)
# Attribution header - optional; end users may remove it.
```

---

## Rules
- Put the header at the **very top** of every source file (after a shebang, if any).
- Keep it short — three lines. Do not expand it into a license block; licensing lives in `LICENSE` once chosen.
- Generated files may carry it too, emitted by the generator.
